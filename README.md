# Hi, I'm YoungWoo Kim 👋

**Ph.D. in Computer Science & Engineering | GPU Computing & Computer Graphics**

I am a researcher and software engineer interested in **GPU-accelerated geometry processing, hardware-accelerated ray tracing, and 3D computing**.

My research focuses on leveraging modern GPU architectures to accelerate computationally intensive geometric algorithms.

*Trying to make GPUs work harder so I don't have to.*

---

## 🔬 Research Interests

- **GPU Computing & HPC** — Parallel algorithms, GPU acceleration, and performance optimization
- **Computer Graphics** — Rendering, ray tracing, and GPU architectures
- **Geometry Processing** — Proximity queries, geometric computation, and spatial data structures
- **3D Reconstruction** — Multi-view reconstruction, visibility, and volumetric representations
- **Spatial Computing** — GPU-accelerated geometry for 3D environments and simulation
